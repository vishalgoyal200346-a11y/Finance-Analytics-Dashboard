
# Finance Analytics Dashboard | Power BI

## Project Overview
This project analyzes financial performance using Power BI and a synthetic dataset containing 1,500 transaction records.

## Key KPIs
- Total Revenue
- Total Expenses
- Net Profit
- Profit Margin
- Transaction Count

## Dashboard Features
- Monthly revenue and expense trends
- Expense analysis by category
- Department-wise financial performance
- Regional filtering
- Financial summary table

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Dataset
The dataset contains transaction dates, departments, categories, regions, amounts, payment methods, and transaction statuses.

## Objective
To monitor financial performance and support data-driven decision-making.
